# Video Interview

Видеособеседование один на один на React, TypeScript и WebRTC.

## Локальный запуск

Требуется Node.js 20 или новее.

```bash
npm install
npm run dev
```

Открой адрес, который покажет Vite. Для доступа к камере браузер должен работать в безопасном контексте: `localhost` или HTTPS.

## Сборка

```bash
npm run build
npm run preview
```

## Публикация

Проект настроен для GitHub Pages репозитория `Video-Interview`.
В GitHub открой **Settings → Pages** и выбери **GitHub Actions** в разделе Build and deployment.
После push в `main` workflow соберёт и опубликует сайт.

## Как тестировать

1. Открой опубликованный сайт в двух отдельных окнах или браузерах.
2. В обоих окнах нажми «Подключиться к собеседованию».
3. Разреши доступ к камере и микрофону.
4. Один клиент создаст offer, второй ответит answer; ICE-кандидаты передаются через signaling WebSocket.
5. Проверь микрофон, камеру и завершение звонка.

## Протокол signaling

Клиенты обмениваются `hello`, `offer`, `answer`, `ice-candidate` и `hangup`.
Сервер пересылает сообщения второму участнику комнаты. Сообщение `peer-left` обрабатывается отдельно.

Для реальной работы между разными сетями может потребоваться TURN-сервер. В проекте пока настроены публичные STUN-серверы.
